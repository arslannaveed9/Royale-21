# Royale 21

Premium blackjack club with real casino rules, member accounts, computer opponents, and live multiplayer tables.

## Play

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000), create a membership, then sit at a table.

## House rules

- 6-deck shoe, shuffled near the cut card
- Blackjack pays 3:2
- Dealer hits soft 17
- Double on any two cards, including after split
- Split matching ranks up to 4 hands (split aces take one card each)
- Late surrender
- Insurance / even money when the dealer shows an Ace
- US-style dealer peek on Ace or ten

Starting bankroll is $10,000. A cashier rebuy appears if your stack falls below $500.
